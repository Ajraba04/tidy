## D01 / D16 / D17 source findings

### CVG-D01-01 — README materially overstates executable capability (High, high confidence)

**Requirement/claim.** The README promises Safe/Normal/Deep cleanup including browser caches, Trash, Git, snapshots, simulators and memory actions (`README.md:18-57`), while product success depends on honest scope (`PRODUCT.md:7-22`) and the approved contract bars unsupported mutation (`design:13,21-26`).

**Observed source.** The only allowlisted effect is DerivedData/deleteContents (`CapabilityRegistry.swift:3-17`, `DerivedDataEffectAdapter.swift:18-48`); all other catalog rows are denied. The discrepancy is not resolved by `README.md` source. **Closure:** amend advertised scope or prove every unavailable row is prominently and accurately unavailable in all tier/Custom routes, then test it with every catalog ID and a human copy review.

### CVG-D16-01 — required approved workflows have no reachable production surface (High, high confidence)

Build Prep, Project Inventory, Pressure Rescue, Ecosystems and Budgets are approved settings/workflows (`design:63-74,150-180`) but no matching `Tidy/{BuildPrep,Projects,Rescue,Ecosystems,Budgets}` production modules exist. `TidyApp.swift:15-75` enumerates all windows and none exposes them. **Closure:** implement each approved workflow with its state/error/confirmation paths, or revise the published/approved scope through the authority process; then perform native UI acceptance.

### CVG-D17-01 — accessibility metadata is not human proof; localization scope needs an explicit decision (Medium, high confidence)

The project records only `Base` and `en` (`project.pbxproj:371-377`), and `Tidy/Resources/Localizable.xcstrings` is the sole localization resource. That is an observed scope, not a defect: neither `PRODUCT.md` nor the approved design promises additional locales. Settings has identifiers/labels/hints (`SettingsView.swift:1539-1661`) but design requires keyboard, VoiceOver, scaling, contrast, long translated text, plurals and units where supported (`audit prompt D17`; `PRODUCT.md:18-22`). **Closure:** state the supported locale scope in release documentation and run keyboard/VoiceOver sessions, including the known AX blank-list reproduction; assess non-English behavior only if a locale is added or promised.
